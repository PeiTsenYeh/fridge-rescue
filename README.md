# 🥬 冰箱救援隊｜一個人，也好好吃飯

**勾選手邊的食材，把冰箱裡的剛剛好，變成一個人的簡單餐點。**

[🌐 立即試用網站](https://peitsenyeh.github.io/fridge-rescue/) · [💻 查看網頁程式](./index.html)

## 💡 作品發想

一個人吃飯時，常常不知道剩下的半顆洋蔥、一碗飯或幾樣蔬菜可以做什麼，也不想為了一餐再買一大袋材料。

「冰箱救援隊」讓使用者勾選現有食材、調味料與設備，找到一人份、簡單吃得飽的料理。餐點包含蛋餅、湯麵、炒飯、飯糰、吐司及燕麥碗，希望減少「今天吃什麼」的煩惱，也讓可食用的剩食有更多利用機會。

## 👤 適合誰使用？

- 一個人吃飯的學生、外宿族與獨居者。
- 想利用現有食材快速準備餐點的人。
- 想減少剩食、建立個人常備食材清單的人。

## ✨ 主要功能

| 功能 | 說明 |
| --- | --- |
| 食材分類與搜尋 | 內建 **42 種食材**，涵蓋主食、蛋白質、蔬菜、調味料、水果、煮好的剩食及乳品與豆漿。 |
| 一人份食譜配對 | 內建 **42 道料理**，優先顯示材料齊全的選項，再列出只差一項材料的選擇。 |
| 設備篩選 | 可選平底鍋、湯鍋、微波爐、電鍋與免開火；今日提案會排除缺少設備的料理。 |
| 時間篩選 | 可選不限時間、10、15 或 20 分鐘內；同組結果依料理時間排序。 |
| 食譜詳情 | 提供一人份用量、預估時間、設備、料理步驟與使用提醒；步驟可勾選完成。 |
| 收藏料理 | 收藏及取消收藏，於「我的收藏」查看，重新開啟仍可保留。 |
| 隨機選餐 | 從目前結果中，挑選食材與設備齊全的料理，減少選擇困難。 |
| 剩食示範 | 提供「飯、蛋和高麗菜」及「熟雞肉＋剩飯」兩種示範組合。 |
| 個人化食材 | 可新增、編輯、刪除自己的食材，最多 50 項，每項 1–24 個字，並檢查重複名稱。 |
| 自訂食材對應 | 例如將「青江菜」對應為「青菜」，讓個人名稱也能參與既有食譜配對。 |
| 手機操作 | 響應式版面，依畫面寬度調整排列。 |

## 🧭 如何使用

1. 開啟 [冰箱救援隊](https://peitsenyeh.github.io/fridge-rescue/)。
2. 勾選現有食材與調味料，確認可用的料理設備。
3. 點「**救援我的一餐**」，或直接查看即時更新的推薦結果。
4. 視需要篩選料理時間，再點「**看看怎麼做**」。
5. 核對食材份量，依步驟料理；喜歡的餐點可點愛心收藏。

第一次使用，可以先按「**先試試：我有飯、蛋和高麗菜**」，看看高麗菜蛋炒飯與缺料提示如何呈現。

### 自訂自己的冰箱

1. 點「**＋ 自訂／編輯我的食材**」。
2. 輸入名稱，例如「青江菜」。
3. 若要參與配對，在「對應食譜食材」選擇「青菜」。
4. 按「新增食材」，該食材會加入個人清單並自動勾選。
5. 之後可在同一視窗編輯名稱、修改對應或刪除。

**未設定對應的自訂食材只作清單記錄，不會自動產生食譜。** 使用者需自行確認對應材料是否適用。金針菇、雞胸肉、豬梅花肉也可分別配對一般菇類、雞肉、豬肉料理。

## 🔎 食材選擇的資料參考

食材清單結合家庭剩食研究、台灣超市平台熱銷消息，以及適合一人料理的設計考量。

- [愛爾蘭 EPA：Food Waste Attitudes & Behaviours 2021](https://www.epa.ie/publications/circular-economy/resources/Food-Waste-Attitudes-%26-Behaviours-2021.pdf)：參考家庭常見的蔬果、麵包、乳品及冰箱剩食類別。
- [英國 WRAP：A Deep Dive into Household Food Waste in the UK, 2022](https://www.wrap.ngo/resources/report/deep-dive-household-food-waste-uk-2022-reasons-patterns-and-opportunities-change)：參考家庭食物浪費的類型與原因。
- [全聯小時達官方熱銷消息](https://www.pxmart.com.tw/about-us/news/全聯新聞/409)：參考奇異果、金針菇、高麗菜、雞胸肉、豬梅花肉等品項，以及文中提到的鮭魚、蛋、鮮奶、無糖豆漿與豆腐。

全聯資料只代表該平台，**不等於全台超市或量販店的民眾最愛排名**。原頁日期與活動年度不一致，因此本作品不將它標示為特定年度榜單。食譜是為本作品整理的料理提案，並非上述研究提供的食譜。資料查閱日期：2026/10/15。

## 🤖 AI 協作與開發過程

1. **釐清想法**：與 AI 討論主題，將需求收斂為「現有食材製作一人份簡單餐點」。
2. **整理規格**：定義使用者、食材與設備選擇、食譜配對、收藏及操作流程。
3. **Vibe Coding 實作**：利用 AI 協助產生 HTML、CSS、JavaScript，整合成單一 `index.html`。
4. **測試與調整**：檢查食材配對、缺料提示、時間篩選、收藏保存與手機版面。
5. **擴充功能**：依資料參考增加食材與料理，再加入個人化食材編輯與對應。
6. **公開作品**：上傳 GitHub，透過 GitHub Pages 發布，並實際開啟公開網站測試。

AI 用於發想、規格整理、程式實作與除錯；**網站本身使用內建食譜規則配對，沒有即時呼叫生成式 AI API**。

## 🛠️ 技術與執行方式

- **HTML**：網頁結構與內容。
- **CSS**：奶油白、蔬菜綠的視覺設計與響應式排版。
- **JavaScript**：食材配對、條件篩選、收藏與自訂食材互動。
- **localStorage**：保存食材選擇、設備、收藏與自訂食材。
- **GitHub Pages**：託管公開網站。

網頁所需的樣式、程式與食譜資料都寫在 **單一 `index.html`**，不需安裝套件或設定 API 金鑰。下載後可直接以瀏覽器開啟，也可使用上方網站連結。

`README.md` 用於介紹專案；`index.html` 是實際執行的網頁。

## 📝 目前限制

- 依食材名稱配對，不會核對冰箱庫存重量、有效期限或營養需求；開煮前仍須確認用量。
- 個人資料只保存在目前瀏覽器，不會跨裝置同步；清除網站資料後會失去紀錄。
- 自訂食材需設定對應才能參與既有食譜配對，無法自動生成全新料理。
- 不提供照片辨識、過敏原自動排除或食物新鮮度判定。
- 料理時間為估計值；步驟勾選在關閉並重新開啟食譜後會重設。

只使用妥善保存、仍可食用的食材。網站提供熟食再加熱及剩飯使用提醒，可參考 [USDA 熟食保存與再加熱](https://www.fsis.usda.gov/food-safety/safe-food-handling-and-preparation/food-safety-basics/leftovers-and-food-safety)及[英國 FSA 食物安全提醒](https://food.blog.gov.uk/2026/09/02/starting-uni-this-september-heres-what-you-need-to-know-about-food-safety/)。
